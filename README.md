# Hi, I'm Alexis

Lead AI Product Engineer based in San Pedro Sula, Honduras. I build automation and AI agents that
remove manual work from how a business actually runs, and I deploy and operate them inside my
clients' environments rather than handing over a prototype.

## What I build

- **Automation that replaces a process, not a task.** At a legal claims operation I mapped the
  onboarding and case-tracking workflows with the people who ran them, rebuilt them in Python,
  Zapier and webhooks, and removed an estimated **150+ hours of administrative work per month**.
- **Pipelines that handle messy real-world input.** A hybrid Python and LLM tool that extracted
  structured data from 50 to 80 inconsistent PDF reports a day into Cloudflare D1, replacing manual
  entry entirely. An AI content pipeline that cut publishing time **85%**, from 60 minutes to under
  8, across an 80+ site network.
- **Production AI agents.** Tool-using agents that run multi-step research unsupervised, built with
  Claude Code and Model Context Protocol tooling. One grew an internal database past **8,000
  qualified records** without manual review.
- **Self-hosted infrastructure for clients.** I run n8n in Docker as separate per-client instances,
  deployed and maintained inside each client's own environment.

## How I work

I start by sitting with the people who do the work and finding the exceptions that only exist in
their heads. Then I decide what actually deserves automating, what needs the process changed
instead, and where a human should stay in the loop. I document what I build and hand it over, so
the team running it day to day does not need me.

I build with Claude Code as my primary method and read every line before it ships.
